# MaterialEditor

**MaterialEditor** — это современный инструмент для визуализации, создания и редактирования игровых материалов и физических свойств (`.mat`, `.def`), написанный на **C++17** с использованием **OpenGL 3.3**, **GLFW**, **GLM**, **GLI** и интерфейса **Dear ImGui**.

Программа создана для удобной настройки параметров шейдеров для PrimeXT, текстурных карт и физических материалов в реальном времени с поддержкой продвинутых эффектов рендеринга.

---

## Основные возможности

### Рендеринг и Шейдерная система
- **PBR-подобный пайплайн** с поддержкой настройки цвета (`albedo`), металличности (`metallic`), шероховатости (`roughness`), отражений (`reflectScale`) и гладкости (`smoothness`).
- **Текстурные карты:**
  - **Diffuse Map** (Диффузная текстура / Альбедо)
  - **Normal Map** (Карта нормалей с расчетом TBN-базиса)
  - **Gloss Map / Specular / AO** (Блик, маска отражений и Ambient Occlusion)
  - **Luma Map** (Карта свечения/самосветящихся элементов)
  - **Bump / Height Map** (Карта высот с поддержкой **Parallax / Bump Mapping** и настраиваемой глубиной рельефа `reliefScale`)
- **Скайбокс (Skybox):** Поддержка загрузки и отображения кубических карт/атласов в качестве окружения с отражениями.

### Управление материалами и физикой (`.mat` & `.def`)
- Парсинг и сохранение файлов материалов (`.mat`).
- Загрузка и редактирование физических свойств материалов (`materials.def` / `scripts/materials.def`):
  - Звуки шагов (`step_sound`)
  - Звуки и эффекты при ударах (`impact_sound`, `impact_parts`, `impact_decal`)
- Автоматическое сканирование директорий игры и сохранение конфигурации редактора (`editor_config.txt`).

### Интерактивная 3D-сцена и UI
- **Переключение примитивов:** Тестирование материалов на **Кубе** (с исправленными корректными UV-координатами на всех гранях) и **Сфере** (32x32).
- **Орбитальная камера:** Вращение вокруг объекта (ЛКМ) и зум (ПКМ).
- **Режимы освещения:** Источник света может быть зафиксирован в пространстве либо следовать за камерой.
- **Ограничение FPS:** Встроенный локер на 60 FPS (с поддержкой Vsync и программной задержкой) для снижения нагрузки на CPU/GPU.
- **Современный интерфейс:** Темная тема оформления на базе **Dear ImGui**.

## Сборка проекта

Проект использует систему сборки **CMake** (версия 3.20 и выше).

### Зависимости (встроены в директорию `external/`):
- [GLFW](https://www.glfw.org/)
- [Glad](https://glad.dav1d.de/)
- [Dear ImGui](https://github.com/ocornut/imgui)
- [GLM](https://github.com/g-truc/glm)
- [GLI (OpenGL Image Library)](https://github.com/g-truc/gli) (для загрузки DDS текстур с мипмапами)

### Инструкция по сборке (Windows / Linux):

1. Клонируйте репозиторий вместе с подмодулями (или убедитесь, что папка `external` заполнена).
2. Создайте папку сборки и сгенерируйте проект:
   ```bash
   mkdir build
   cd build
   cmake -DCMAKE_BUILD_TYPE=Release ..
   ```
3. Соберите проект:
   ```bash
   cmake --build . --config Release
   ```
4. Исполняемый файл будет помещен в директорию сборки (`bin/` или корень `build`).

## Структура проекта

- `src/main.cpp` — Точка входа, главный цикл приложения, логика камеры, рендеринга и лока FPS.
- `src/MaterialSystem.cpp / .h` — Логика загрузки, сохранения и управления текстурами и физическими свойствами материалов.
- `src/EditorUI.cpp / .h` — Интерфейс пользователя на базе Dear ImGui.
- `src/Shader.cpp / .h` — Загрузка и компиляция OpenGL шейдеров.
- `src/Config.cpp / .h` — Чтение и запись конфигурации редактора (`editor_config.txt`).
- `src/shaders/basic.vert / basic.frag` — Вершинный и пиксельный шейдеры (включая расчет света, нормалей, бликов, luma и Parallax mapping).
- `src/cube_data.h` & `src/sphere_data.h` — Вершинные буферы примитивов.
